# Arena do Raciocínio Lógico

Jogo multiplayer para primeira aula de raciocínio lógico.

## Links após ativar o GitHub Pages

- Alunos: `https://renissonsouza-crypto.github.io/teste3/`
- Professor: `https://renissonsouza-crypto.github.io/teste3/?professor=1`

## Fluxo

1. O professor abre o painel e cria uma sala.
2. O sistema gera um PIN de 6 dígitos.
3. Os alunos entram pelo celular, informam PIN e nome.
4. O professor inicia a partida.
5. Cada questão tem 20 segundos.
6. Acertos rápidos e sequências de acertos valem mais pontos.
7. Após cada rodada aparece o ranking.
8. Ao final aparece o pódio.

Backend: Supabase. Front-end: HTML, CSS e JavaScript publicados no GitHub Pages.
